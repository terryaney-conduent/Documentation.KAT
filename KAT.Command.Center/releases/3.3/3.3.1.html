No More Work Item Hocus Pocus...

Rows in query results no longer vanish while you are looking at them. When an edit you save, or an automatic poll, means a work item no longer matches the query or your current filters, its row stays where it was, striped, and its tooltip explains why. After you save an edit, Command Center checks the query right away instead of waiting for the next poll. If a later change brings the item back into the query, the stripes go away.

Striped rows stay until you choose. Use Remove from Query Results in the row's actions menu to hide one, or refresh or leave the query to clear them all. New matches still appear automatically.

Each query can now start exactly the way you want. The new Default Sort in Settings › Work Items › Queries picks the column and direction a query opens with: sort a To Do query by priority and a Recent Tasks query by last changed. New and existing queries start with Changed (newest first), and clicking a column header still re-sorts the open query without changing the setting.
